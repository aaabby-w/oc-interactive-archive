# Language and bilingual typography

## Current mode

Chinese is the primary reading language. English participates in the composition as labels, indices, and typographic rhythm. The site does not currently provide full `/zh` and `/en` locale routes.

Examples:

```text
角色
CHARACTER

档案
ARCHIVE
```

## Implementation

- Shared interface text lives in `content/site.ts`, not inside view components.
- Content types allow paired `zh` and `en` display fields when both are meaningful.
- English may be shorter than Chinese and need not duplicate long prose.
- Set the document language to Simplified Chinese.

## Future compatibility

Do not design APIs that prevent a later full language switch. If long English text is introduced, add it to the content records first; decide URL strategy only when full translated coverage exists.
