# Sitemap

```text
/
├── /characters
├── /characters/[slug]
├── /world
├── /archive
├── /gallery
└── /residence/[slug]
```

## Route intent

- `/`: immersive entry and later landing-page story.
- `/characters`: character index sourced from the registry.
- `/characters/[slug]`: modular character profile.
- `/world`: regions, organizations, systems, history, places, events, and rules.
- `/archive`: in-world documents presented through their native media language.
- `/gallery`: image-led work with categories, metadata, and full-screen viewing.
- `/residence/[slug]`: optional character residence; only generated for eligible characters.

Phase 1 routes may show restrained holding states. They establish contracts, not finished experiences.
