# Roadmap

## Phase 0 — definition and design system

Status: **active / documented**

Product rules, sitemap, visual direction, motion rules, content model, Residence boundaries, 3D delivery, language, performance, and deployment are documented.

## Phase 1 — technical skeleton

Status: **active**

- App routes exist.
- Typed character registry and template exist.
- Shared bilingual UI copy is isolated from components.
- The first viewport proves the art direction with replaceable placeholder media.
- No GSAP or Three.js is shipped.

## Phase 2 — static landing page

Status: **active / partial**

The opening, featured-character transition, world/archive navigation, and footer exist. Formal character art and remaining content chapters are deferred until real material is supplied.

## Phase 3 — landing scroll story

Status: **active / first pass**

The homepage includes a pinned opening, image zoom, copy recession, section reveals, parallax, and a fine-pointer follower. Continue after real character art establishes focal points and mobile crop behavior.

## Phase 4 — complete character system

Implement modular profile sections and desktop/mobile character selectors.

## Phase 5 — world, archive, and gallery

Create world-taxonomy views, medium-specific archive documents, and a metadata-aware full-screen gallery.

## Phase 6 — Residence integration

Integrate the first web-ready 3D room with camera, light, controls, loading, fallback, and responsive quality settings.

## Phase 7 — autonomous life

Build a pure character-state engine, then map it to scene anchors, animation clips, props, light, and limited visitor interactions.

## Phase 8 — Spatial Mode

Add capability-detected device orientation with permission, normalization, clamping, damping, orientation changes, reduced motion, and touch/pointer fallbacks.

## Phase 9 — mobile audit

Review navigation, type, crops, touch targets, scroll distance, 3D camera, gallery, selectors, and Spatial Mode on real devices.

## Phase 10 — performance and polish

Add no new features. Optimize loading, media, bundles, animation cleanup, WebGL memory, and network resilience.

## Phase 11 — deployment and mirrors

Publish from one repository to selected hosts. Add a Lite variant only when testing justifies it.

## Phase 12 — real-device testing

Test desktop browsers, iPhone Safari/Chrome, Android Chrome, and representative mainland-China mobile and Wi-Fi networks.

## Phase 13 — portfolio framing

Document process, technology, and credits outside the core in-world flow.

## Phase 14 — productization

Separate reusable components from client content and define scope/pricing dimensions.

## Phase 15 — client workflow

Standardize discovery, scope, deposit, sitemap/moodboard, still design, motion, preview, revisions, final payment, launch, warranty, maintenance, and licensing.
