# Visual direction

## Thesis

**Luminous conservatory archive** — an editorial world built from expansive artwork, precise bilingual typography, thin orbital geometry, paper texture, and restrained mineral color.

The preferred theme is light: warm mineral white, pale mint, fog blue-gray, and deep green-gray type. A one-click dark theme keeps the same composition and shifts it into a low-light observational mood; it is not a separate design.

Character dossier routes frame this theme change as a reading-room light. Their
light state keeps the character's pale surface color and a soft overhead glow;
their dark state derives a deep ink-blue ground from the same character accent.
The control says “开灯 / 关灯” on dossier pages while remaining the compact
sun–moon control elsewhere.

Character profile routes follow the same color logic: character records provide
the light surface palette, while dark mode derives low-light surfaces from the
global ink colors and the character accent. Character-specific inline colors
must not pin a section to the light theme.

The supplied *Reverse: 1999* reference is used for principles only: Chinese/English hierarchy, sparse asymmetry, large serif display type, layered media, fine linework, and a small warm accent on a nearly black field. Do not copy its logo, characters, layout, text, assets, or distinctive branded motifs.

## Type roles

- Chinese display: self-hosted Noto Serif SC (SIL Open Font License 1.1), with Songti system faces retained only as fallbacks. The bundled webfont keeps the intended Ming-style forms consistent across desktop and mobile.
- English display: classical editorial serif, large and airy.
- Metadata: compact sans serif, uppercase where appropriate, generous tracking.
- Body: Chinese-first, readable at 16px or larger.

English is not a duplicate translation line by default. It can label, index, pace, or frame the Chinese content.

## Composition

- Prefer open fields and decisive anchors over grids of cards.
- Corners are mostly square; curves belong to image masks, orbital lines, and intentional silhouettes.
- Use asymmetry with a visible underlying alignment system.
- Decorative English remains subordinate to real navigation and content.
- Media frames should support portraits of different proportions without encoding a specific character.

## Homepage artwork

The opening viewport is artwork-led and edge-to-edge. Typography floats over the image rather than reserving a separate portrait card. The current conservatory image is a temporary, original, no-character art-direction asset; replace it when official OC art is available.

## Placeholder policy

Missing art is presented honestly as an awaiting-media aperture. Do not use a fake character silhouette or unrelated stock image. The empty state should still demonstrate crop, scale, focal zone, and future layering.
