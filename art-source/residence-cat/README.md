# Original residence companion

This cream-and-taupe, blue-eyed stylized cat is independently generated by
`scripts/build-residence-cat.py` from mathematical surfaces and hand-authored
details, guided by the user's two supplied visual references.

The supplied `bicolor_cat.glb` was inspected only at the GLB JSON metadata level
to understand a quadruped skeleton, skin, and animation organization. Its binary
chunk was not read during that inspection. It is not imported by the generator,
copied into this repository, or used at runtime. No source mesh, vertex data,
UVs, textures, weights, transforms, or animation keyframes were transferred.

Source deliverables:

- `companion-cat.blend`: editable original mesh, palette UVs, 25-bone armature,
  hand-assigned blended skin weights, and five original actions.
- `palette.png`: independently generated 128 x 128 palette atlas.
- `scripts/build-residence-cat.py` (from the repository root):
  reproducible generator; no input asset required.
- `public/models/residence-cat/companion-cat.glb`: runtime export with embedded
  texture, skin, and Idle / Walk / Rest / Greet / Jump clips.

The refined surface uses a bounded 0.018-unit voxel union of the original
anatomical volumes and relaxed smooth normals. Original proportions, swatches,
25 bone names/hierarchy and five action names remain intact. Skin weights are
transferred from the independently authored source, then normalized. Two
materials separate continuous interpolated fur color from the small palette-UV
eye/nose details. The original third-party reference is never used in this step.
The runtime model is about 2.2 MB, with approximately 27k authoring vertices.
This is a stylized web model, not a photorealistic or production-film animal.

Regenerate using Blender 5.1:

```sh
blender --background --python scripts/build-residence-cat.py
```

Render output is written to the ignored `outputs/` directory. Only the GLB is
served to visitors; the Blender source and palette source remain outside public.
